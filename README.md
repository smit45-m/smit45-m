## About Me:

I'm **Smit Pathak** — an **Artificial Intelligence** undergrad at **NIT Rourkela**, passionate about building autonomous multi-agent systems, deep learning architectures, and production-ready intelligent applications.

* **GenAI & Agentic AI:** Architecting autonomous multi-agent workflows using **LangGraph**, **CrewAI**, **LangChain**, and advanced **RAG** pipelines with vector databases.
* **Deep Learning & NLP:** Designing sequence models (BiLSTM), fine-tuning Hugging Face Transformers (**LoRA / PEFT**), and developing vision-language diagnostic models.
* **Backend & MLOps:** Building high-throughput **FastAPI** microservices, containerizing with **Docker**, and orchestrating auto-scaling deployments on **Kubernetes** with **CI/CD** pipelines.
* **Key Projects:**
  * 🤖 **Multi-Agent AI Research Assistant:** 4-agent collaborative RAG research platform with CrewAI & LangGraph.
  * 📊 **Deep NLP Sentiment Analysis Pipeline:** BiLSTM opinion mining microservice scaling to 5,000+ reviews/min.
  * 🩻 **Chest Radiograph Multi-Pathology Diagnostic:** DenseNet-121 + Grad-CAM diagnostic tool with automated LLM report generation.
